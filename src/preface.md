# 前言

> 官方书教你写 Rust；这本书教你别被 Rust 卡住。

## 这本书写给谁

写给**已经能写、但总被卡住**的人。

如果你符合下面任意一条，这本书就是为你写的：

- 语法都会，但一遇到借用检查器报错就靠"试试加个 `clone()`"蒙过去；
- 写泛型 + 生命周期时，编译器报错和你的直觉完全不一致；
- 能写 `async fn`，但说不清 `Pin` 为什么存在、`Send` 为什么"传染"；
- 看过 `unsafe` 的文档，但不敢确定自己写的到底 sound 不 sound；
- 读过官方 *The Rust Programming Language*，也翻过 *Rust for Rustaceans*，但到了异步和 unsafe 的深水区还是断片。

这本书**不讲入门**。变量、函数、`match`、`Result` 这些，默认你已经会了。

## 为什么叫"深水区"

Rust 的难，不在语法，在**心智模型**。

| 区域 | 对应的难点 |
|---|---|
| 浅水区 | 语法、类型、所有权的基本规则 —— 官方书已经讲透 |
| 深水区 | 借用检查器背后的真实规则、生命周期与 variance、trait 系统的组合爆炸 |
| 洋流 | 并发：`Send`/`Sync` 如何让所有权规则在多线程下依然成立 |
| 深渊 | 异步：`Future`、`Pin`、executor，以及它们与生命周期的纠缠 |
| 海沟 | `unsafe`：如何用不安全的代码，构造出安全的抽象 |

这本书只写后四层。

## 怎么读

- **五部分可以独立看**，但强烈建议按顺序读前两部分（所有权 → trait），因为后面所有内容都建立在这两块的心智模型上。
- **每部分末尾有实战项目**。不要跳过。读懂了和写出来之间，隔着一整条借用检查器。
- 代码都在 **Rust 1.98.1 / edition 2024** 上验证过。

## 版本说明

本书基于：

- **Rust 1.98.1**（stable，2026-09-03 发布）
- **Edition 2024**
- 示例代码用 `rustc 1.98.1` / `cargo 1.98.1` / LLVM 22.1.8 验证

> **关于补丁版本**：补丁版本（1.98.2、1.98.3…）只修 bug，不引入语言变化，本书示例在 1.98.x 全系列上都应可编译。若某天某章因语言演进过时，以本章顶部的"最后验证"标注为准。

## 一条约定

书中所有 `unsafe` 代码，都会明确写出它**依赖的安全不变式（safety invariant）**，以及**调用者是安全的前提**。这不是可选项——这是写 `unsafe` 唯一正确的方式。如果你看到一段 `unsafe` 没有解释它为什么 sound，那就是这本书的 bug。
